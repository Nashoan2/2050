# المملكة للإلكترونيات - نظام الفواتير والتقارير وكشوفات الحسابات

تطبيق ويب حديث ومتكامل لإدارة الفواتير والاشتراكات، وحسابات العملاء، وسندات القبض والصرف، وكشوفات الحسابات، مع أدوات مالية ذكية ومحولات عملات.

## المميزات الرئيسية

- **إدارة الفواتير**: إنشاء وتعديل الفواتير (نقدية أو أجل) مع تفقيط المبالغ باللغة العربية، وحساب تاريخ الانتهاء تلقائياً، وإضافة الأصناف والخدمات الإضافية.
- **إدارة العملاء والحسابات**: دليل عملاء متكامل، أرقام حسابات تلقائية، أرصدة محدثة لحظياً، وتسجيل سندات القبض والصرف.
- **كشوفات الحسابات المتقدمة**: كشف حساب تفصيلي للعميل مع فلترة بالفترات (اليوم، هذا الشهر، الشهر الماضي، 3 أشهر، 6 أشهر، مخصص) مع إجمالي المدين والدائن والرصيد.
- **طباعة وتصدير PDF ولقطة شاشة**: تجهيز فواتير وكشوفات حسابات قابلة للطباعة بدقة عالية وتصديرها بصيغة PDF والتقاط صور لها.
- **وضع العرض للعميل**: شاشة خاصة لعرض تفاصيل الفاتورة والمبلغ الإجمالي للعميل بشكل جذاب وواضح.
- **الأدوات المالية المدمجة**:
  - محول العملات المباشر (ريال يمني، دولار، ريال سعودي) بأسعار صرف قابلة للتعديل.
  - حاسبة النسبة المئوية الذكية بأربعة أوضاع (بسيطة، زيادة، خصم، إكمال).
  - آلة حاسبة رقمية متكاملة.
- **التخصيص الكامل والنسخ الاحتياطي**:
  - خيارات تخصيص ألوان وثيمات الواجهة وترتيب الأزرار.
  - خيارات تنسيق التقارير، وتغيير نوع الخط (Cairo, Tajawal, Almarai, Amiri) ومقياس الحجم.
  - إنشاء نسخ احتياطية محلية واستيراد وتصدير ملفات JSON لقاعدة البيانات.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

يعمل خادم التطوير على المنفذ `3000` على المضيف `0.0.0.0`.
